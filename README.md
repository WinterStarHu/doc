# Oracle 19c Scheduler 文档归档

Oracle Database 19c 文档中 Scheduler 相关内容的本地 Markdown 归档，方便对照实现。

## 内容

- `refrn`（Database Reference）：82 个 SCHEDULER 数据字典视图（`ALL_/DBA_/USER_SCHEDULER_*`），每个含完整列定义表（Column / Datatype / NULL / Description）。
- [`DBMS_SCHEDULER`](DBMS_SCHEDULER.md)（PL/SQL Packages and Types Reference）：包内全部过程/函数，含语法代码块与参数表。

索引见 [INDEX.md](INDEX.md)。原始 HTML 存于 `raw/`（被 Oracle 模板 JS 用 `visibility:hidden` 遮蔽，故转成 Markdown 阅读）。
