# 统计

统计信息相关：DBE_STATS。

---

## DBE_STATS

高级包DBE_STATS提供了统计信息管理的功能，包括锁定、解锁、回退统计信息和清除历史统计信息等。DBE_STATS支持的接口请参见表1。
DBE_STATS不支持临时表。
#### 接口介绍

| 接口名称 | 描述 | 权限要求 |
|---|---|---|
| DBE_STATS.LOCK_TABLE_STATS | 锁定表级统计信息。 | 使用该接口时，用户必须对指定的表拥有与ANALYZE命令相同的权限。有关权限的详细信息，请参见ANALYZE \| ANALYSE。 |
| DBE_STATS.LOCK_PARTITION_STATS | 锁定分区级统计信息。 |  |
| DBE_STATS.LOCK_COLUMN_STATS | 锁定列级统计信息。 |  |
| DBE_STATS.LOCK_SCHEMA_STATS | 锁定指定schema下所有表相关的统计信息。 | 调用该接口时，会锁定该schema下所有当前用户有ANALYZE权限的表，对于没有权限的表直接跳过。调用该接口需拥有指定schema的USAGE权限。 |
| DBE_STATS.UNLOCK_TABLE_STATS | 解锁表级统计信息。 | 使用该接口时，用户必须对指定的表拥有与ANALYZE命令相同的权限。有关权限的详细信息，请参见ANALYZE \| ANALYSE。 |
| DBE_STATS.UNLOCK_PARTITION_STATS | 解锁分区级统计信息。 |  |
| DBE_STATS.UNLOCK_COLUMN_STATS | 解锁列级统计信息。 |  |
| DBE_STATS.UNLOCK_SCHEMA_STATS | 解锁指定schema下所有表相关的统计信息。 | 调用该接口时，会解锁该schema下所有当前用户有ANALYZE权限的表，对于没有权限的表直接跳过。调用该接口需拥有指定schema的USAGE权限。 |
| DBE_STATS.RESTORE_TABLE_STATS | 回退表级统计信息到指定时间点。 | 使用该接口时，用户必须对指定的表拥有与ANALYZE命令相同的权限。有关权限的详细信息，请参见ANALYZE \| ANALYSE。 |
| DBE_STATS.RESTORE_PARTITION_STATS | 回退分区级统计信息到指定时间点。 |  |
| DBE_STATS.RESTORE_COLUMN_STATS | 回退列级统计信息到指定时间点。 |  |
| DBE_STATS.RESTORE_SCHEMA_STATS | 回退指定schema下所有表相关的统计信息到指定时间点。 | 调用该接口时，会回退该schema下所有当前用户有ANALYZE权限的表，对于没有权限的表直接跳过。调用该接口需拥有指定schema的USAGE权限。 |
| DBE_STATS.PURGE_STATS | 清除指定时间节点前的所有历史统计信息。 | 只有初始用户可调用该接口。 |
| DBE_STATS.GET_STATS_HISTORY_RETENTION | 获取历史统计信息的保留时间。 | - |
| DBE_STATS.GET_STATS_HISTORY_AVAILABILITY | 获取最早可用的历史统计信息的时间。 | - |
| DBE_STATS.CREATE_STAT_TABLE | 创建用于保存统计信息的统计表。 | 要调用此过程创建统计表，需要用户拥有在指定schema与指定tablespace下创建表和创建索引的权限。 |
| DBE_STATS.DROP_STAT_TABLE | 删除用于保存统计信息的统计表。 | 要调用此过程删除统计表，需要用户拥有在指定schema下删除表和删除索引的权限。 |
| DBE_STATS.EXPORT_INDEX_STATS | 检索指定索引的统计信息并存储在用户统计信息表中。 | 使用该接口时，用户必须对指定的表拥有与ANALYZE命令相同的权限。有关权限的详细信息，请参见ANALYZE \| ANALYSE。调用此过程将统计信息导出到用户统计信息表，需要对用户统计信息表具有SELECT、INSERT、DELETE和UPDATE的权限。 |
| DBE_STATS.EXPORT_TABLE_STATS | 检索指定表的统计信息并存储在用户统计信息表中。 |  |
| DBE_STATS.EXPORT_COLUMN_STATS | 检索指定列的统计信息并存储在用户统计信息表中。 |  |
| DBE_STATS.EXPORT_SCHEMA_STATS | 检索指定schema的统计信息并存储在用户统计信息表中。 |  |
| DBE_STATS.EXPORT_DATABASE_STATS | 用于检索指定database的统计信息，并存储在用户统计信息表中。 | 调用该接口时，会导出当前database下所有当前用户有ANALYZE权限的用户表，对于没有权限的表直接跳过。 调用此过程将统计信息导出到用户统计信息表，需要对用户统计信息表具有SELECT、INSERT、DELETE和UPDATE的权限。 |
| DBE_STATS.IMPORT_INDEX_STATS | 从用户统计信息表中检索指定索引的统计信息，并将其写回系统表。 | 使用该接口时，用户必须对指定的表拥有与ANALYZE命令相同的权限。有关权限的详细信息，请参见ANALYZE \| ANALYSE。调用此过程将统计信息从用户统计信息表导回系统表，需要对用户统计信息表具有SELECT、INSERT、DELETE和UPDATE的权限。 |
| DBE_STATS.IMPORT_TABLE_STATS | 从用户统计信息表中检索指定表的统计信息，并将其写回系统表。 |  |
| DBE_STATS.IMPORT_COLUMN_STATS | 从用户统计信息表中检索指定列的统计信息，并将其写回系统表。 |  |
| DBE_STATS.IMPORT_SCHEMA_STATS | 从用户统计信息表中检索指定schema的统计信息，并将其写回系统表。 |  |
| DBE_STATS.IMPORT_DATABASE_STATS | 从用户统计信息表中检索指定database的统计信息，并将其写回系统表。 | 调用该接口时，导入当前database下所有当前用户有ANALYZE权限用户表的统计信息，对于没有权限的表直接跳过。调用此过程将统计信息导出到用户统计信息表，需要对用户统计信息表具有SELECT、INSERT、DELETE和UPDATE的权限。 |
| DBE_STATS.SET_COLUMN_STATS | 设置列相关的统计信息，包括单列、多列、表达式统计信息。 | 使用该接口时，用户必须对指定的表拥有与ANALYZE命令相同的权限。有关权限的详细信息，请参见ANALYZE \| ANALYSE。 |
| DBE_STATS.SET_INDEX_STATS | 设置索引相关的统计信息。 |  |
| DBE_STATS.SET_TABLE_STATS | 设置表相关的统计信息。 |  |
| DBE_STATS.DELETE_COLUMN_STATS | 删除列相关的统计信息，包括单列、多列、表达式统计信息。 |  |
| DBE_STATS.DELETE_INDEX_STATS | 删除索引相关的统计信息。 |  |
| DBE_STATS.DELETE_TABLE_STATS | 删除表相关的统计信息。 |  |
| DBE_STATS.DELETE_SCHEMA_STATS | 删除schema下所有表、索引、列相关的统计信息。 |  |
| DBE_STATS.GET_TABLES_BY_SQLID | 获取Unique SQL ID对应语句所有涉及的表，如果含有多张表，则返回多行记录。 | 使用该接口时，用户的权限需要满足以下其中一种情况： 用户是初始用户。用户拥有MONADMIN访问权限。 |
| DBE_STATS.ANALYZE_SQLID | 获取Unique SQL ID对应语句所有涉及的表，以及收集对应表的统计信息。对于收集成功的表，如果含有多张表，则返回多行记录。 | 使用该接口时，用户的权限需要满足以下其中一种情况： 用户是初始用户。用户拥有MONADMIN访问权限，同时拥有相应表与ANALYZE命令相同的权限。有关权限的详细信息，请参见ANALYZE \| ANALYSE。 |
| dbe_stats_tools.py | 用于库级统计信息导出和导入，以及计划调优语句元信息导出。 | 导出统计信息时，需要具备相应的接口或命令（DBE_STATS.CREATE_STAT_TABLE、DBE_STATS.EXPORT_DATABASE_STATS、\COPY TO、DBE_STATS.DROP_STAT_TABLE）的权限，以及指定导出目录的读写权限。导入统计信息时，需要具备相应接口或命令（DBE_STATS.CREATE_STAT_TABLE、DBE_STATS.EXPORT_DATABASE_STATS、\COPY FROM、DBE_STATS.DROP_STAT_TABLE）的权限，以及指定导出目录下文件的读取权限。导出语句元信息时，需要数据库的系统管理员权限，以及指定目录的读写权限。 |

```
DBE_STATS.LOCK_TABLE_STATS(
   ownname   VARCHAR2,
   tabname   VARCHAR2
);
```

| 参数 | 类型 | 是否允许为空 | 描述 |
|---|---|---|---|
| ownname | varchar2 | 是 | 要锁定的表所属的schema名称，该参数为空时，默认为当前schema。 |
| tabname | varchar2 | 否 | 要锁定的表的名称。 |

  - 可以通过查看表的reloptions中的stat_state状态获取该表的锁定状态。
  - 当一个表处于锁定状态时，其统计信息无法更新。
  - 当ownname参数值设置为null时使用当前schema，需将behavior_compat_options参数值设置为bind_procedure_searchpath。
示例：
```
-- 建表。
gaussdb=# CREATE SCHEMA dbe_stats_lock;
CREATE SCHEMA
gaussdb=# SET CURRENT_SCHEMA=dbe_stats_lock;
SET
gaussdb=# CREATE TABLE t1(a int,b int);
CREATE TABLE
-- 锁定表，查看其锁定状态。
gaussdb=# CALL DBE_STATS.LOCK_TABLE_STATS(ownname=>'dbe_stats_lock',tabname=>'t1');
 lock_table_stats
------------------
(1 row)
gaussdb=# SELECT relname,instr(reloptions::text,'stat_state=locked',1,1) <> 0  AS exist_lock FROM PG_CLASS WHERE relname='t1' AND relnamespace = (SELECT oid FROM PG_NAMESPACE WHERE nspname='dbe_stats_lock');
 relname | exist_lock
---------+------------
 t1      | t
(1 row)
-- 锁定后analyze, 发生报错。
gaussdb=# ANALYZE t1;
ERROR:  The statistics is locked, cannot be updated.
-- 删除表、删除命名空间。
gaussdb=# DROP TABLE t1;
DROP TABLE
gaussdb=# DROP SCHEMA dbe_stats_lock;
DROP SCHEMA
```
```
DBE_STATS.LOCK_PARTITION_STATS(
    ownname     VARCHAR2,
    tabname     VARCHAR2,
    partname    VARCHAR2
);
```

| 参数 | 类型 | 是否允许为空 | 描述 |
|---|---|---|---|
| ownname | varchar2 | 是 | 要锁定的分区所属的schema名称，该参数为空时，默认为当前schema。 |
| tabname | varchar2 | 否 | 要锁定的分区所属的表的名称。 |
| partname | varchar2 | 否 | 要锁定的分区的名称。 |

  - 可以通过查看该分区的reloptions中的stat_state状态获取该表的锁定状态。
  - 当该分区或该表所属的表处于锁定状态时，其统计信息无法更新。
  - 当ownname参数值设置为null时使用当前Schema，需将behavior_compat_options参数值设置为bind_procedure_searchpath。
示例：
```
-- 建表。
gaussdb=# CREATE SCHEMA dbe_stats_lock;
CREATE SCHEMA
gaussdb=# SET CURRENT_SCHEMA=dbe_stats_lock;
SET
gaussdb=# CREATE TABLE upart_table(a int, b int, c int) PARTITION BY RANGE(a)
 (
    PARTITION p1 VALUES LESS THAN(1200),
    PARTITION p2 VALUES LESS THAN(2400),
    PARTITION p3 VALUES LESS THAN(MAXVALUE)
 );
CREATE TABLE
-- 锁定一个分区，其他分区及表不受影响。
gaussdb=# CALL DBE_STATS.LOCK_PARTITION_STATS(ownname=>'dbe_stats_lock',tabname=>'upart_table',partname=>'p1');

----------------------
(1 row)
gaussdb=# SELECT relname,instr(reloptions::text,'stat_state=locked',1,1) <> 0 AS exist_lock FROM PG_CLASS WHERE relname='upart_table';

-------------+------------

(1 row)
gaussdb=# SELECT relname,instr(reloptions::text,'stat_state=locked',1,1) <> 0 AS exist_lock FROM PG_PARTITION WHERE parentid='upart_table'::REGCLASS ORDER BY 1;
   relname   | exist_lock
-------------+------------
 p1          | t
 p2          | f
 p3          | f
 upart_table | f
(4 rows)
-- 删除表、命名空间。
gaussdb=# DROP TABLE upart_table;
DROP TABLE
gaussdb=# DROP SCHEMA dbe_stats_lock;
DROP SCHEMA
```
```
DBE_STATS.LOCK_COLUMN_STATS(
    ownname     VARCHAR2,
    tabname     VARCHAR2,
    colname     VARCHAR2,
    partname    VARCHAR2 DEFAULT NULL
);
```

| 参数 | 类型 | 是否允许为空 | 描述 |
|---|---|---|---|
| ownname | varchar2 | 是 | 要锁定的列所属的schema的名称，该参数为空时，默认为当前schema。 |
| tabname | varchar2 | 否 | 要锁定的列所属的表的名称。 |
| colname | varchar2 | 否 | 要锁定的列的名称。 |
| partname | varchar2 | 是 | 要锁定的列所属的分区的名称，默认为空。 |

  - 当partname为空时，默认锁定该列表级统计信息。
  - 若不存在该表的列级统计信息，则锁定可执行成功，但实际未生效。
  - 可查看PG_STATISTIC、PG_STATISTIC_EXT中的stastate获取锁定状态。
  - 锁定多列时，需先查询PG_STATISTIC_EXT中的staextname字段获取多列别名作为colname入参传入。
  - 当某一列被锁定或其所属的表或分区被锁定时，其统计信息无法更新，该列被锁定的信息不会回显，需要在日志中通过DEBUG2级别的DBE_STATS的logging_module查看。
  - 当ownname参数值设置为null时使用当前schema，需将behavior_compat_options参数值设置为bind_procedure_searchpath。
示例：
```
-- 建表，收集统计信息。
gaussdb=# CREATE SCHEMA dbe_stats_lock;
CREATE SCHEMA
gaussdb=# SET CURRENT_SCHEMA=dbe_stats_lock;
SET
gaussdb=# CREATE TABLE t1(a int,b int);
CREATE TABLE
gaussdb=# INSERT INTO t1 VALUES(generate_series(1,100),1);
INSERT 0 100
gaussdb=# ANALYZE t1;
ANALYZE
-- 锁定列后，查看列的锁定状态。
gaussdb=# CALL DBE_STATS.LOCK_COLUMN_STATS(ownname=>'dbe_stats_lock',tabname=>'t1',colname=>'a');
 lock_column_stats
-------------------
(1 row)
gaussdb=# SELECT staattnum,stastate FROM PG_STATISTIC WHERE starelid='t1'::REGCLASS ORDER BY 1,2;
 staattnum | stastate
-----------+----------
         1 | l
         2 | u
(2 rows)
-- 删除表、命名空间。
gaussdb=# DROP TABLE t1;
DROP TABLE
gaussdb=# DROP SCHEMA dbe_stats_lock;
DROP SCHEMA
```

```
DBE_STATS.UNLOCK_PARTITION_STATS(
    ownname     VARCHAR2,
    tabname     VARCHAR2,
    partname    VARCHAR2

```

| 参数 | 类型 | 是否允许为空 | 描述 |
|---|---|---|---|
| ownname | varchar2 | 是 | 要解锁的分区所属的schema的名称，该参数为空时，默认为当前schema。 |

```
   ownname       VARCHAR2,
   tabname       VARCHAR2,
   partname      VARCHAR2 DEFAULT NULL,
   stattab       VARCHAR2,
   statid        VARCHAR2 DEFAULT NULL,
   cascade       BOOLEAN  DEFAULT TRUE,
```

| 参数 | 类型 | 是否允许为空 | 描述 |

| --command/-c | 否 | 在语句元信息收集模式下，指定SQL文本。要求是单条可执行EXPLAIN的SQL语句，且不能带有EXPLAIN关键字。explain_analyze模式下仅支持SELECT语句。 |

    - query.sql：存放输入的SQL语句文本。
      - explain.log：对SQL语句进行EXPLAIN的结果。
      - plantrace.log：计划生成的PLAN TRACE信息。
