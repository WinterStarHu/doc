# 统计

统计信息相关（对应 GaussDB DBE_STATS）。

---

## DBMS_STATS

**包用途**：收集与管理优化器统计信息。默认数据库自动收集，本包用于专门场景；可收集表/列/索引/系统统计，支持并行，含优化器统计顾问（Optimizer Statistics Advisor）。只有存于数据字典的优化器统计影响 CBO。

**接口清单（全部 125 个）**：

| Subprogram | 说明 |
|---|---|
| ALTER_STATS_HISTORY_RETENTION | 修改统计历史保留值 |
| CANCEL_ADVISOR_TASK | 取消一次优化器统计顾问执行 |
| CONFIGURE_ADVISOR_FILTER | 为顾问任务配置过滤列表 |
| CONFIGURE_ADVISOR_OBJ_FILTER | 为顾问任务配置对象过滤器 |
| CONFIGURE_ADVISOR_OPR_FILTER | 为顾问任务配置操作过滤器 |
| CONFIGURE_ADVISOR_RULE_FILTER | 为顾问任务配置规则过滤器 |
| CONVERT_RAW_VALUE | 将最小值/最大值/直方图端点实际值的内部表示转为特定类型值 |
| CONVERT_RAW_VALUE_NVARCHAR | 同上，NVARCHAR |
| CONVERT_RAW_VALUE_ROWID | 同上，ROWID |
| COPY_TABLE_STATS | 缩放后将源[子]分区统计复制到目标[子]分区 |
| CREATE_ADVISOR_TASK | 为优化器统计顾问创建顾问任务 |
| CREATE_EXTENDED_STATS | 为用户指定列组或表达式在表中创建虚拟列 |
| CREATE_STAT_TABLE | 在 ownname 的 schema 创建名为 stattab、可保存统计的表 |
| DELETE_COLUMN_STATS | 删除列相关统计 |
| DELETE_DATABASE_PREFS | 删除所有表的统计首选项 |
| DELETE_DATABASE_STATS | 删除整个数据库的统计 |
| DELETE_DICTIONARY_STATS | 删除所有字典 schema（SYS、SYSTEM 及数据库组件 schema）的统计 |
| DELETE_FIXED_OBJECTS_STATS | 删除所有固定表的统计 |
| DELETE_INDEX_STATS | 删除索引相关统计 |
| DELETE_PENDING_STATS | 删除已收集但未发布的私有统计 |
| DELETE_PROCESSING_RATE | 删除给定统计源的吞吐率；未指定源则删所有源 |
| DELETE_SCHEMA_PREFS | 删除指定属主所有表的统计首选项 |
| DELETE_SCHEMA_STATS | 删除 schema 相关统计 |
| DELETE_SYSTEM_STATS | 删除系统统计 |
| DELETE_TABLE_PREFS | 删除指定 schema 指定表的统计首选项 |
| DELETE_TABLE_STATS | 删除表相关统计 |
| DIFF_TABLE_STATS_IN_HISTORY | 比较表在两个过去时间戳的统计 |
| DIFF_TABLE_STATS_IN_PENDING | 比较待定统计与某时间戳或字典统计 |
| DIFF_TABLE_STATS_IN_STATTAB | 比较表来自两个不同源的统计 |
| DROP_ADVISOR_TASK | 删除指定优化器统计顾问任务 |
| DROP_EXTENDED_STATS | 删除为用户指定扩展创建的统计项 |
| DROP_STAT_TABLE | 删除 CREATE_STAT_TABLE 创建的用户统计表 |
| EXECUTE_ADVISOR_TASK | 执行先前创建的优化器统计顾问任务 |
| EXPORT_COLUMN_STATS | 取某列统计存入 stattab 标识的用户统计表 |
| EXPORT_DATABASE_PREFS | 导出所有表的统计首选项 |
| EXPORT_DATABASE_STATS | 取数据库所有对象统计存入 statown.stattab |
| EXPORT_DICTIONARY_STATS | 取所有字典 schema 统计存入 stattab |
| EXPORT_FIXED_OBJECTS_STATS | 取固定表统计存入 stattab |
| EXPORT_INDEX_STATS | 取某索引统计存入 stattab |
| EXPORT_PENDING_STATS | 导出已收集并作为待定存储的统计 |
| EXPORT_SCHEMA_PREFS | 导出指定属主所有表的统计首选项 |
| EXPORT_SCHEMA_STATS | 取 schema 所有对象统计存入 stattab |
| EXPORT_SYSTEM_STATS | 取系统统计存入用户统计表 |
| EXPORT_TABLE_PREFS | 将指定表的统计首选项导出到指定统计表 |
| EXPORT_TABLE_STATS | 取某表统计存入用户统计表 |
| FLUSH_DATABASE_MONITORING_INFO | 将所有表的内存监控信息刷入字典 |
| GATHER_DATABASE_STATS | 收集数据库所有对象统计 |
| GATHER_DICTIONARY_STATS | 收集字典 schema（SYS、SYSTEM 及 RDBMS 组件）统计 |

| GET_INDEX_STATS | 获取所有索引相关信息 |

| GET_STATS_HISTORY_AVAILABILITY | 获取统计历史可用的最早时间戳 |

| GET_SYSTEM_STATS | 从 stattab 取系统统计，stattab 为 NULL 则从字典取 |

| IMPLEMENT_ADVISOR_TASK | 实施优化器统计顾问给出的建议 |
| IMPORT_COLUMN_STATS | 从 stattab 取某列统计存入字典 |

| IMPORT_FIXED_OBJECTS_STATS | 从 stattab 取固定表统计存入字典 |
| IMPORT_INDEX_STATS | 从 stattab 取某索引统计存入字典 |
