# 工具与杂项

工具与杂项（对应 GaussDB DBE_UTILITY、DBE_RAW、DBE_RANDOM、DBE_MATCH、DBE_SESSION、DBE_APPLICATION_INFO、DBE_ALERT）。

---

## DBMS_UTILITY

**包用途**：提供各种工具子程序。

**接口清单（全部）**：

| Subprogram | 说明 |
|---|---|
| ACTIVE_INSTANCES | 返回活动实例 |
| ANALYZE_DATABASE | 分析数据库中所有表、簇、索引（已弃用，改用 DBMS_STATS） |
| ANALYZE_PART_OBJECT | 分析给定表与索引（已弃用） |
| ANALYZE_SCHEMA | 分析 schema 中所有表、簇、索引（已弃用） |
| CANONICALIZE | 规范化给定字符串 |
| COMMA_TO_TABLE | 将逗号分隔名表转为 PL/SQL 名表 |
| COMPILE_SCHEMA | 编译指定 schema 中所有过程、函数、包、视图、触发器 |
| CREATE_ALTER_TYPE_ERROR_TABLE | 创建用于 ALTER TYPE EXCEPTION 子句的错误表 |
| CURRENT_INSTANCE | 返回当前连接实例号 |
| DATA_BLOCK_ADDRESS_BLOCK | 取数据块地址的块号部分 |
| DATA_BLOCK_ADDRESS_FILE | 取数据块地址的文件号部分 |
| DB_VERSION | 返回数据库版本信息 |
| EXEC_DDL_STATEMENT | 执行 parse_string 中的 DDL 语句 |
| EXPAND_SQL_TEXT | 递归用视图子查询替换输入 SQL 中的视图引用 |
| FORMAT_CALL_STACK | 格式化当前调用栈 |
| FORMAT_ERROR_BACKTRACE | 格式化从当前错误点到异常处理器的回溯 |
| FORMAT_ERROR_STACK | 格式化当前错误栈 |
| GET_CPU_TIME | 返回当前 CPU 时间（百分之一秒） |
| GET_DEPENDENCY | 显示对象的依赖（已弃用，无替代） |
| GET_ENDIANNESS | 获取数据库平台字节序 |
| GET_HASH_VALUE | 计算给定字符串的哈希值 |
| GET_PARAMETER_VALUE | 获取指定 init.ora 参数值（已弃用，直接查 v$parameter） |
| GET_SQL_HASH | 用 MD5 计算给定字符串哈希值 |
| GET_TIME | 返回当前时间（百分之一秒） |
| GET_TZ_TRANSITIONS | 按 regionid 返回时区转换 |
| INVALIDATE | 使数据库对象失效并（可选）改其 PL/SQL 编译参数 |
| IS_BIT_SET | 检查给定 RAW 值中指定位是否设置 |
| IS_CLUSTER_DATABASE | 数据库是否运行于集群数据库模式 |
| MAKE_DATA_BLOCK_ADDRESS | 由文件号与块号构造数据块地址 |
| NAME_RESOLVE | 解析给定名称 |
| NAME_TOKENIZE | 调用解析器解析给定名称 |
| OLD_CURRENT_SCHEMA | 返回 SYS_CONTEXT('USERENV','CURRENT_SCHEMA') 的会话值 |
| OLD_CURRENT_USER | 返回 SYS_CONTEXT('USERENV','CURRENT_USER') 的会话值 |
| PORT_STRING | 返回唯一标识 Oracle 与 OS 版本的字符串 |
| SQLID_TO_SQLHASH | 将 SQL ID 转为哈希值 |
| TABLE_TO_COMMA | 将 PL/SQL 名表转为逗号分隔名表 |
| VALIDATE | 使无效数据库对象变有效 |
| WAIT_ON_PENDING_DML | 等待直到对所列表加锁且早于指定 SCN 的其它事务提交或回滚 |

## UTL_RAW

**包用途**：操作 RAW 数据类型的 SQL 函数（普通 SQL 函数不能操作 RAW，且 PL/SQL 不允许 RAW/CHAR 重载）。还含 COBOL 数字格式与 RAW 互转。非数据库专有，故前缀 UTL。

| Subprogram | 说明 |
|---|---|
| BIT_AND | 对 r1、r2 按位与，返回结果 RAW |
| BIT_COMPLEMENT | 对 r 按位取反 |
| BIT_OR | 按位或 |
| BIT_XOR | 按位异或 |
| CAST_FROM_BINARY_DOUBLE | 返回 BINARY_DOUBLE 的 RAW 二进制表示 |
| CAST_FROM_BINARY_FLOAT | 返回 BINARY_FLOAT 的 RAW 二进制表示 |
| CAST_FROM_BINARY_INTEGER | 返回 BINARY_INTEGER 的 RAW 二进制表示 |
| CAST_FROM_NUMBER | 返回 NUMBER 的 RAW 二进制表示 |
| CAST_TO_BINARY_DOUBLE | 将 RAW 二进制转为 BINARY_DOUBLE |
| CAST_TO_BINARY_FLOAT | 转为 BINARY_FLOAT |
| CAST_TO_BINARY_INTEGER | 转为 BINARY_INTEGER |
| CAST_TO_NUMBER | 转为 NUMBER |
| CAST_TO_NVARCHAR2 | 将 RAW 转为 NVARCHAR2 |
| CAST_TO_RAW | 将 VARCHAR2 转为 RAW |
| CAST_TO_VARCHAR2 | 将 RAW 转为 VARCHAR2 |
| COMPARE | 比较 r1 与 r2 |
| CONCAT | 最多拼接 12 个 RAW |
| CONVERT | 将 r 从 from_charset 转为 to_charset |
| COPIES | 返回 n 份 r 拼接 |
| LENGTH | 返回 RAW 字节长度 |
| OVERLAY | 用 overlay RAW 覆盖 target RAW 从 pos 起 len 字节 |
| REVERSE | 反转字节序列 |
| SUBSTR | 从 r 的 pos 起取 len 字节 |
| TRANSLATE | 按 from_set/to_set 翻译字节 |
| TRANSLITERATE | 按 from_set/to_set 音译字节 |
| XRANGE | 返回从 start_byte 到 end_byte 的所有单字节编码 |

## DBMS_RANDOM

**包用途**：内置随机数生成器（不用于加密）。

| Subprogram | 说明 |
|---|---|
| INITIALIZE | 用种子初始化包 |
| NORMAL | 返回正态分布随机数 |
| RANDOM | 生成随机数 |
| SEED | 重置种子 |
| STRING | 获取随机字符串 |
| TERMINATE | 终止包 |
| VALUE | 返回 [0,1) 随机数（38 位精度）；重载返回 [low,high) 随机数 |

| Subprogram | 说明 |

| CURRENT_IS_ROLE_ENABLED | 指定角色当前是否启用 |
| FREE_UNUSED_USER_MEMORY | 在大量内存操作后回收未用内存 |
| GET_PACKAGE_MEMORY_UTILIZATION | 描述静态包内存使用 |
| IS_ROLE_ENABLED | 指定角色在会话是否启用 |
| IS_SESSION_ALIVE | 指定会话是否活跃 |
| LIST_CONTEXT | 返回当前会话的活动命名空间与上下文列表 |
| MODIFY_PACKAGE_STATE | 对会话中所有活动 PL/SQL 程序单元的会话状态执行指定动作 |
| RESET_PACKAGE | 取消实例化会话中所有包 |
| SESSION_IS_ROLE_ENABLED | 会话级指定角色是否启用 |
| SESSION_TRACE_DISABLE | 重置调用会话的会话级 SQL 跟踪 |
| SESSION_TRACE_ENABLE | 为调用会话启用会话级 SQL 跟踪 |
| SET_CONTEXT | 设置或重置上下文属性值 |
| SET_EDITION_DEFERRED | 请求切换到指定 edition |
| SET_IDENTIFIER | 设置标识符 |
| SET_NLS | 设置全球化支持（NLS） |
| SET_ROLE | 设置角色 |
| SET_SQL_TRACE | 开关跟踪 |
| SLEEP | 挂起会话指定时长 |
| SWITCH_CURRENT_CONSUMER_GROUP | 切换用户当前会话的当前资源使用者组 |
| UNIQUE_SESSION_ID | 返回当前连接所有会话唯一的标识符 |

## DBMS_APPLICATION_INFO

**包用途**：注册应用以让管理员/调优专家按模块跟踪性能与资源使用；应用名与动作记录于 V$SESSION 与 V$SQLAREA。

| Subprogram | 说明 |
|---|---|
| READ_CLIENT_INFO | 读取当前会话 client_info 字段 |
| READ_MODULE | 读取当前会话 module 与 action 字段 |
| SET_ACTION | 设置当前模块内当前动作名 |
| SET_CLIENT_INFO | 设置会话 client_info 字段 |
| SET_MODULE | 设置当前运行模块名 |
| SET_SESSION_LONGOPS | 在 V$SESSION_LONGOPS 表设一行 |

## DBMS_ALERT

**包用途**：数据库告警。应用可对数据注册告警、等待（WAITONE/WAITANY），数据被改时触发器 SIGNAL 自动唤醒等待会话。

| Subprogram | 说明 |
|---|---|
| REGISTER | 注册接收告警消息 |
| REMOVE | 取消某告警的通知 |
| REMOVEALL | 移除本会话注册的所有告警 |
| SET_DEFAULTS | 设置轮询间隔 |
| SIGNAL | 发出告警（向已注册会话发消息） |
| WAITANY | 等待 timeout 秒接收会话已注册的任一告警 |
| WAITONE | 等待 timeout 秒接收命名告警的消息 |
