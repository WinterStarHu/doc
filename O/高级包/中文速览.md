# Oracle 高级包 · 中文速览

> 22 个 Oracle 高级包（DBMS_* / UTL_*）的中文概述与接口清单。过程名保留英文（与 GaussDB `G/高级包/` 对应），说明译为中文。详细语法与参数见各分类文件（英文原版）及 `O/en/arpls/`。

## 定时任务

### DBMS_SCHEDULER
**包用途**：调度相关函数与过程，可在任何 PL/SQL 程序中调用，用于创建与管理定时任务、程序、调度、作业类、凭据等。
**接口清单**：见 [`定时任务.md`](定时任务.md)（已精译，含 CREATE_JOB/SET_ATTRIBUTE/RUN_JOB/STOP_JOB/CREATE_PROGRAM/CREATE_SCHEDULE 等）。

## 输出与调试

### DBMS_OUTPUT
**包用途**：从存储过程、包、触发器发送消息，特别适合显示 PL/SQL 调试信息。PUT/PUT_LINE 向缓冲区写信息，GET_LINE/GET_LINES 读出；包禁用时所有调用被忽略。

| Subprogram | 说明 |
|---|---|
| DISABLE | 禁用消息输出 |
| ENABLE | 启用消息输出 |

| NEW_LINE | 结束 PUT 创建的行 |
| PUT | 向缓冲区写部分行 |
| PUT_LINE | 向缓冲区写整行 |

**包用途**：收集 PL/SQL 应用的剖析（性能）数据，用于性能改进或代码覆盖率。在 PL/SQL 虚拟机层收集每行执行次数、耗时等，存入数据库表供查询。

| Subprogram | 说明 |
|---|---|
| FLUSH_DATA | 刷新用户会话收集的剖析数据 |
| GET_VERSION | 获取本 API 版本 |
| INTERNAL_VERSION_CHECK | 校验本包版本与数据库实现兼容 |
| PAUSE_PROFILER | 暂停剖析数据收集 |
| RESUME_PROFILER | 恢复剖析数据收集 |
| START_PROFILER | 在用户会话开始剖析数据收集 |
| STOP_PROFILER | 停止剖析数据收集 |

## XML

### DBMS_XMLDOM
**包用途**：访问 XMLType 对象，实现 DOM（文档对象模型）API，用于 HTML/XML 文档。可访问、修改、删除、添加文档节点。接口清单（共 100+，按节点类型分组，节选，完整见 `XML.md`）：DOMDocument（创建文档/元素/属性/注释/CDATA/处理指令/文本节点等）、DOMNode（节点增删改查、父子兄弟遍历、命名空间）、DOMElement（属性读写、标签名）、DOMAttr（属性值/名）、DOMCharacterData（数据追加/删除/插入/替换/子串）、DOMDocumentType（实体/记法）、DOMNamedNodeMap/DOMNodeList（按名/索引取项）、以及 WRITETO*（写缓冲/CLOB/文件）、MAKEXXX/ISNULL（节点类型转换/判空）等。

### DBMS_XMLPARSER
**包用途**：XML 解析器，将 XML 文档解析为 DOM 树以便访问修改（本版本未抽取到独立清单表，详见 `XML.md`）。

### DBMS_XMLGEN
**包用途**：将 SQL 查询结果转为规范 XML 格式，以 CLOB 返回；用 C 编写编译进内核。

## 安全与 ILM

### DBMS_OBFUSCATION_TOOLKIT
**包用途**：数据加密/解密工具（已基本被 DBMS_CRYPTO 取代；本版本未抽取到独立清单，详见 `安全与ILM.md`）。

### DBMS_ILM
**包用途**：用 ADO（自动数据优化）策略实现信息生命周期管理（ILM）。支持立即评估/执行 ADO 任务、向任务添加/移除对象、预览策略评估。

| Subprogram | 说明 |
|---|---|
| ADD_TO_ILM | 将指定对象加入某 ADO 任务并评估其上的 ADO 策略 |
| ARCHIVESTATENAME | 返回行归档启用表的 ORA_ARCHIVE_STATE 列值 |
| EXECUTE_ILM | 执行一个 ADO 任务 |
| EXECUTE_ILM_TASK | 执行先前已评估的 ADO 任务 |
| PREVIEW_ILM | 评估参数指定范围内的所有 ADO 策略 |
| REMOVE_FROM_ILM | 从某 ADO 任务移除指定对象 |
| STOP_ILM | 停止为某 ADO 任务创建的 ADO 相关作业 |

### DBMS_COMPRESSION
**包用途**：汇集压缩相关信息，含估计分区/非分区表可压缩性、获取已压缩表的行级压缩信息，辅助做压缩决策。

| Subprogram | 说明 |
|---|---|
| GET_COMPRESSION_RATIO | 分析表的压缩比，给出可压缩性信息 |
| GET_COMPRESSION_TYPE | 返回指定行的压缩类型 |

### DBMS_HEAT_MAP
**包用途**：在块/区/段/对象/表空间各级导出热图（数据访问与修改跟踪），用于 ILM 与 ADO。SYSTEM/SYSAUX 表空间不跟踪。

| Subprogram | 说明 |
|---|---|
| BLOCK_HEAT_MAP | 返回表段每块的最后修改时间 |
| EXTENT_HEAT_MAP | 返回表段的区级热图统计 |
| OBJECT_HEAT_MAP | 返回对象所有段的最小/最大/平均访问时间 |
| SEGMENT_HEAT_MAP | 返回给定段的热图属性 |
| TABLESPACE_HEAT_MAP | 返回表空间所有段的最小/最大/平均访问时间 |
