# Part VI Monitoring Database Activity with Auditing

Part VI describes how to monitor database activity with auditing.
- Introduction to Auditing Privileged users can create policies that track the changes that all users, including other privileged users, make in the database.
- Configuring Audit Policies Unified auditing supports custom unified audit policies, predefined unified audit policies, and fine-grained auditing.
- Administering the Audit Trail Users who have been granted the AUDIT_ADMIN role can manage the audit trail, archive the audit trail, and purge audit trail records.
