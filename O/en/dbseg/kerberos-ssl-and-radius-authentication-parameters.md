# C Kerberos, TLS, and RADIUS Authentication Parameters

The `sqlnet.ora` and the database initialization files provide Kerberos, RADIUS, or TLS authentication parameters.
- Parameters for Clients and Servers Using Kerberos Authentication Oracle Database provides client and server parameters for using Kerberos authentication.
- Parameters for Clients and Servers Using Transport Layer Security Oracle provides parameters to control Transport Layer Security authentication.
- Parameters for Clients and Servers Using RADIUS Authentication Oracle provides parameters for RADIUS authentication.
