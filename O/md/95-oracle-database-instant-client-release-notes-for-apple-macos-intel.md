The following section contains information about the issue related to Oracle Database
Instant Client 19c:


Pro*C Does Not Support C99 Headers
The Pro*C parser fails to recognize C99 syntax in system headers on the supported
Apple Mac OS X releases.
This issue has no workaround.
This issue is tracked with Oracle bug 16061064.
