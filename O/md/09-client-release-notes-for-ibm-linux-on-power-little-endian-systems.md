Other Known Issues
The following section contains information about issues related to Oracle Database
19c and associated products:


Pro*C Does Not Support C99 Headers
Pro*C parser fails to recognize C99 headers on Linux on POWER Systems.
This issue has no workaround.
This issue is tracked with Oracle bug 6142780.
