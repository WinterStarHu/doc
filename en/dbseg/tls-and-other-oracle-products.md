# TLS and Other Oracle Products

Configure TLS consistently across Oracle Database products and deployment patterns.
Provider behavior still applies when TLS is used with other Oracle products. The next-generation provider supports TLS 1.2 and TLS 1.3, while the legacy provider supports TLS 1.0 through TLS 1.2.
- Transport Layer Security Connections in an Oracle Real Application Clusters Environment Configure TLS endpoints, wallets, certificates, listeners, and clients in an Oracle RAC environment.
