# Part IV Securing Data on the Network

Part IV describes how to secure data on the network.
- Configuring Oracle Database Native Network Encryption and Data Integrity You can configure native Oracle Net Services data encryption and data integrity for both servers and clients.
- Configuring Transport Layer Security Encryption You can configure Oracle Database 19c to use TLS to protect data in transit and authenticate endpoints.
- Configuring the Thin JDBC Client Network Oracle Database native network encryption and strong authentication enables thin Java Database Connectivity (JDBC) clients to securely connect to Oracle databases.
